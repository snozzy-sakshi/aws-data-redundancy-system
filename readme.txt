# Data Redundancy Detection System Using AWS

## Project Overview
This project detects duplicate and redundant data using AWS cloud services.

## AWS Services Used
- AWS Lambda
- API Gateway
- Amazon RDS
- CloudWatch
- S3

## Features
- Duplicate detection
- False positive detection
- Data validation
- Cloud database integration
- Logging and monitoring

## Technologies
- Python
- AWS
- MySQL
- RapidFuzz

## Architecture
User → API Gateway → Lambda → RDS
